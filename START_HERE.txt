## 🎬 NEXT STEPS

1. Read Quick Start (5 min)
   → Open: ADMIN_QUICKSTART.md

2. Login to Admin Panel
   → Visit: http://localhost:3000/admin
   → Email: admin@wanderly.com
   → Password: admin123

3. Create Your First Destination (2 min)
   → Admin → Destinations → Add Destination
   → Fill: Name, Location, Price, Description
   → Upload: Hero image
   → Check: Publish on website
   → Click: Save destination

4. Build Your First Itinerary (5 min)
   → Admin → Itineraries → Build Itinerary
   → Add: Title, Duration, Locations, Price
   → Link: Related destinations
   → Add: Day-by-day plan (format: "Day title | Description")
   → Check: Publish package
   → Click: Create itinerary

5. View on Live Website
   → http://localhost:3000/destinations
   → http://localhost:3000/packages
